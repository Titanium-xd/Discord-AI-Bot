===================================================

Your bot has been configured with Gemini AI! Follow these steps:

STEP 1: Create your .env file
--------------------------------
Create a file named ".env" in the project root with this content:

DISCORD_TOKEN=YOUR_DISCORD_BOT_TOKEN_HERE
GEMINI_API_KEY=AIzaSyCITfNm8ESWxNiMOuid9Hi6NvvqmGyZ1f4

(Optional - restrict to one channel):
CHANNEL_ID=1234567890123456789

You can also run this command in PowerShell:
Copy and paste from the "CREATE_ENV.ps1" file


STEP 2: Get your Discord Bot Token
-----------------------------------
1. Go to: https://discord.com/developers/applications
2. Click "New Application" (or select existing)
3. Go to "Bot" section on the left
4. Click "Reset Token" or "Copy" to get your bot token
5. IMPORTANT: Enable "Message Content Intent" under "Privileged Gateway Intents"
6. Go to "OAuth2" > "URL Generator"
7. Select: bot, applications.commands
8. Select permissions: Send Messages, Read Message History
9. Copy the URL and open in browser to invite bot to your server


STEP 3: Install Dependencies (if not already done)
---------------------------------------------------
npm install


STEP 4: Run the Bot
--------------------
npm start

or

node index.js


TROUBLESHOOTING
===============
- Make sure your Discord token is correct
- Enable "Message Content Intent" in Discord Developer Portal
- Check that bot has permission to read/send messages
- Look at console for any error messages


Your Gemini API key is already configured!
Now just add your Discord bot token to the .env file.
